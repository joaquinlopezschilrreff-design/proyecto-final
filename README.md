# 📚 StudyMood

StudyMood es una aplicación web desarrollada con **Python, Flask y SQLite** para ayudar a los estudiantes a organizar sus apuntes y resúmenes por materia.

## ✨ Funciones

* 🔐 Registro de usuarios
* 🔑 Inicio de sesión
* 📚 Gestión de materias
* 📝 Creación y edición de resúmenes
* 💾 Guardado automático en SQLite
* 👤 Sesiones de usuario
* ✅ Validación de formularios
* 📧 Verificación básica de formato de correo
* 🚫 Prevención de correos duplicados

## 🛠️ Tecnologías utilizadas

* Python
* Flask
* SQLite
* HTML5
* CSS3

## 🚀 Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/StudyMood.git
```

2. Entrar al proyecto:

```bash
cd StudyMood
```

3. Instalar Flask:

```bash
pip install flask
```

4. Ejecutar la aplicación:

```bash
python main.py
```

5. Abrir en el navegador:

```text
http://127.0.0.1:5000
```
